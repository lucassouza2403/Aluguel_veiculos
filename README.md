# 🚗 Sistema de Aluguel de Veículos

Este projeto foi desenvolvido em Python com o objetivo de gerenciar o aluguel de veículos, permitindo o cadastro de clientes, controle de frota e acompanhamento das locações.

---

## 📋 Funcionalidades

- Cadastro de veículos disponíveis para aluguel
- Registro de clientes
- Controle de contratos de locação
- Cálculo automático de valores de aluguel
- Relatórios básicos de utilização

---

## 🛠 Tecnologias utilizadas

- _Python 3.x_
- Bibliotecas padrão do Python (sem dependências externas)
